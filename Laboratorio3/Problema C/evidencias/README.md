# Evidencias

- `compilacion`: captura del programa compilando en Microchip Studio.
- `simulacion`: capturas del circuito, LCD, UART y los cuatro colores en Proteus.
- `armado_fisico`: fotos del circuito real y pruebas con los plasticos.
- `videos`: videos mostrando la simulacion y, mas adelante, el armado fisico.

Las evidencias se agregaran a medida que se realicen las pruebas.
