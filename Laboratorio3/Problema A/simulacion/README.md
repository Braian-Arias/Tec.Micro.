# Simulacion en Proteus

Esta carpeta contiene el proyecto editable de Proteus.

## Contenido

- `ControlTemperatura_Problema_A.pdsprj`: circuito de Proteus.
- `firmware/Medidor de temperatura.hex`: programa cargado en el ATmega328P.

No subir archivos `.workspace`, porque guardan configuraciones personales de la
computadora y no son necesarios para abrir el proyecto.
